# Обчислення площі геометричних фігур

**Варіант №3**

## Опис програми

Програма написана мовою Java та призначена для обчислення площі трьох геометричних фігур: квадрата, прямокутника та круга.

У програмі використано шаблон **Abstract Superclass (Абстрактний суперклас)**.

При створенні кожної фігури виводиться повідомлення «Об'єкт створено», після чого обчислюється та виводиться її площа.

## Структура програми

- `Figure.java` — абстрактний батьківський клас, який містить конструктор та абстрактний метод `calculateArea()`.
- `Square.java` — клас квадрата, який обчислює площу за формулою S = a × a.
- `Rectangle.java` — клас прямокутника, який обчислює площу за формулою S = a × b.
- `Circle.java` — клас круга, який обчислює площу за формулою S = π × r².
- `Main.java` — головний клас, який створює об'єкти та виводить результати обчислень.

## Як запустити програму

1. Встановити Java JDK (версія 21 або сумісна).
2. Завантажити репозиторій на комп'ютер.
3. Відкрити папку проєкту у Visual Studio Code або терміналі.
4. Виконати команди:

```bash
javac *.java
java Main
```
